**Work Activity Tracker (WAT)** – a lightweight productivity tool for tracking focused work sessions and breaks.

**⚠️ Project Status:** This project has been discontinued and is now archived. It is kept for historical and reference purposes only.

Key functionality:
* Work time tracking
* Break time tracking
* Break counter
* Session duration with start/end timestamps
